Kale Savunması - Chrome Oynama Rehberi

Java ile açmak (JDK 18+):
1) Proje klasörüne gir:
   cd /workspace/codex
2) Java'nın web sunucusunu başlat:
   jwebserver -p 8000
3) Chrome'da aç:
   http://127.0.0.1:8000

Python YOKSA diğer seçenekler:

Seçenek A) Node.js varsa
1) Proje klasörüne gir:
   cd /workspace/codex
2) Sunucuyu başlat:
   npx serve . -l 8000
3) Chrome'da aç:
   http://127.0.0.1:8000

Seçenek B) VS Code kullanıyorsan
1) Klasörü VS Code ile aç.
2) "Live Server" eklentisini kur.
3) index.html üzerinde sağ tık -> "Open with Live Server".

Seçenek C) Sadece Chrome ile (eklentili)
1) Chrome Web Store'dan "Web Server for Chrome" benzeri local server eklentisi kur.
2) /workspace/codex klasörünü kök klasör olarak seç.
3) Verilen local adresi Chrome'da aç.

Python VARSA klasik yöntem:
1) cd /workspace/codex
2) python3 -m http.server 8000
3) http://127.0.0.1:8000

Notlar:
- Oyun dosyalarını çift tıklayıp direkt açmak yerine local server ile çalıştır.
- Oyun açılınca komutan adını yazıp "Oyunu Başlat" butonuna bas.
- `jwebserver` komutu bulunamazsa JDK sürümünü kontrol et (JDK 18+ gerekir).
