# Nova Dominion 2K (Offline Browser)

Tarayıcıda çalışan, OGame tarzından ilham alan offline uzay strateji oyunu.

## Çalıştırma

```bash
cd webgame
python3 -m http.server 8000
```

Aç:
- http://localhost:8000

## Yeni modüller

- İttifak sistemi (kurma + bot daveti)
- İttifak savaşları (puanlı takip)
- Mesajlaşma sistemi (oyuncu -> bot)
- Görev süreleri / görev kuyruğu (saldırı, taşıma, casusluk, recycler)
- Gerçek zamanlı görev çizelgesi (dakika/saniye geri sayım)
- Marketplace (kaynak dönüşümü)
- Ticaret sözleşmeleri (periyodik otomatik takas)
- Officers/Commander modülü
- Güncel teknoloji hatları: Quantum AI, Otonom Drone Ağ, Yörüngesel Fabrikasyon
- Çok pahalı unique üniteler: Titan Dreadnought, Quantum Ark
- 2K hedefli görsel kalite: yoğun yıldız alanı, ünite kartları, SVG ünite görselleri, animasyonlar
- Görev rapor ekranı
- Save/Load sistemi (localStorage + JSON export/import)

## Not

Bu proje resmi OGame klonu değildir; offline oynanış için ilham alan bağımsız bir çalışmadır.
